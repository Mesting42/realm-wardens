# 幻域守城 · REALM WARDENS

原创浏览器 3D 奇幻策略塔防游戏。采用明亮的奇幻沙盘、连续地形、Blender 制作流程与本地 GLB 模型、填色物件图标和原创 Web Audio 音乐与音效。游戏逻辑、关卡、塔和场景为本项目原创；英雄和部分怪物以 KayKit / Quaternius 的 CC0 模型为基础制作，完整来源与许可随项目提供。

完整流程：主菜单 → 模式选择 → 地图详情 → 英雄选择 → 建造与战斗 → 胜败结算 → 解锁或再次挑战。

公开源码：[Mesting42/realm-wardens](https://github.com/Mesting42/realm-wardens)。

开发接手请先读[交接文档](HANDOFF.md)，其中记录项目结构、启动方式、最新修复和验证范围。

## 直接游玩

公网游戏已部署到 Cloudflare Pages：[mest-rw.pages.dev](https://mest-rw.pages.dev/)。均衡画质入口：[直接开始](https://mest-rw.pages.dev/?safe=1)。手机、平板和电脑均可通过互联网打开，网址中的 `rw` 来自游戏英文名 REALM WARDENS。部署方式、后续更新与验证范围见 [Cloudflare部署说明](docs/CLOUDFLARE.md)。存档仍保存在访问设备的浏览器中。

双击 `启动游戏.cmd`。启动器会检测 Node.js 和依赖，优先使用 5175 空闲端口，在后台启动生产预览，验证 HTTP 后打开浏览器。如果端口已有本游戏，会直接复用；若被其他程序占用，会选择新的空闲端口。它不会停止其他项目或修改防火墙。

本次交付地址：

- 电脑：[http://127.0.0.1:5175/](http://127.0.0.1:5175/)
- 手机 / 平板：首次运行本机启动器后，使用启动器显示的局域网地址。

局域网预览仅适用于当前电脑所在网络，手机与电脑需要相互可达，且电脑保持运行。公网地址不依赖本机预览服务。切换网络后再次运行启动器，以它显示的新局域网地址为准。整屏黑屏排查后的均衡访问请在预览地址后加 `?safe=1`，详见交接文档。

开发和构建需要 Node.js 22.12 或更新版本。游戏运行建议使用支持 WebGL 2 的 Chrome、Edge 或 Safari，并开启硬件加速。

```powershell
Set-Location -LiteralPath '<project-root>'
npm install
npm run dev
```

开发服务器监听 `0.0.0.0:5175`，严格占用指定端口。已在运行时无需再次启动。

```powershell
npm run build
npm run preview
```

生产预览默认使用 `0.0.0.0:5176`。双击启动器使用 5175，交付时已运行的是 5175 上的生产构建。所有游戏素材、模型、图标和声音随项目提供，无游戏运行素材 CDN 或付费接口；安装依赖后可以在本机离线运行。77 个 GLB 合计约 46 MB，首次载入有进度提示，Blender 只用于制作资源，游玩不需要启动 Blender。

拖动和多指操作不会触发建造、英雄移动或技能释放。窗口旋转、触控取消、失焦和后台切换会清理输入状态；战斗中失焦自动暂停。旋转不会重开关卡。游戏没有虚拟移动轮盘。

手机和平板横屏战斗采用浮动操作布局，地图铺满屏幕。左上为生命、金币、波次，右上为速度、暂停和设置，左下为英雄生命条与两个技能，右下为开波或剩余敌军数。五个地图工具收进右下独立按钮，展开后可以缩放、还原、切换建造网格和全屏；地图指令或主要操作会收起工具。常驻操作按钮至少44px，兼顾刘海和底部安全区。默认视角自动容纳当前地图的道路、城门和完整城镇，打开建造面板不会重新缩放地图。英雄倒下时头像显示重生秒数；点击头像可以查看准确生命和护盾。电脑正常尺寸保留指挥栏布局。布局与验证范围见 `docs/MOBILE-BATTLE.md`。

手机和平板的波次提示为资源栏旁单行文字，显示2.2秒后消失，分别提示来袭、新路线或首领，不在地图中显示独立大提示框。暂停或竖屏时冻结提示，后续波次仍立即自动接续。画质切换同步阴影贴图实际尺寸，避免均衡/高清切换后出现远处错位的塔与怪物影子。

Boss名称、生命条及“当前生命 / 最大生命”在顶部中间与左右资源栏、速度/暂停/设置栏同排，区域完全透明、不加底色。首领及其父级顶栏关闭背景模糊，名称和生命数字使用深绿色文字配细浅色外缘，避免手机和平板上粗描边覆盖字形。生命数字显示完整数值并使用千位分隔，极长数字可分两行，顶部仍保持44px高。小横屏按可用空间缩短血条并避让两侧，Boss击败或重新挑战后隐藏；阶段事件仍使用短暂提示。

手机和平板仅支持横屏游玩。首次打开显示横屏提示，点击“进入游戏”后请求浏览器原生全屏，再尝试锁定横屏；支持自动旋转的浏览器会自动转向。浏览器不支持或拒绝这些能力时，提示手动横持设备，横屏下仍可窗口游玩。竖屏时覆盖游戏并暂停模拟、画面和音效；转回横屏后点击“继续战斗”，关卡、金币和防线保留。退出全屏后不会反复强制重新进入，但移动端仍须横屏。电脑保持窗口入口，也可在设置切换全屏。

网页无法绕过浏览器的用户点击要求，也无法保证所有手机浏览器都允许页面全屏和方向锁定，尤其是系统或浏览器未提供相应能力的场景。上述流程使用真实 Fullscreen / Screen Orientation API，不用 CSS 旋转画布模拟横屏。图鉴滚动条采用深绿轨道与浅绿滑块，支持鼠标、键盘和触控滚动。

## 战役与无尽

战役包含三个区域，每区四关。关卡道路采用独立布局，包含单路弯道、双路汇流、分叉出口和多方向进攻。每张地图的合法空地采用 2 单位网格；道路、时空门、基地、建筑、障碍物和友军占据的位置不可建造。第一关有 129 个候选格子和 52 个初始障碍，后续关卡随道路布局变化。

十二张战役和三张无尽地图统一以200金币开局，重新挑战也从200开始。可以先建一座奥术塔加一座箭塔（110+80，剩10），或两座箭塔（80+80，剩40），再通过战斗与清障逐步完善防线。普通敌军维持先前约30%的生命强化、20%的近战攻击强化和约30%的基础击杀金币削减，关卡成长继续生效。战役已逐关编排波次：前两波单路轻兵，第3波才增加第二路；第10关第5波、第12关第6波才增加第三路，以三名一组的小队错峰出怪。无需开战前清障攒钱，也可以建立可通关的防线。第一波手动开始，后续仍在清波后立即续上，并提示新路线和末波首领。

每关最后一波都有一位具名首领，在护卫队后出场。十二个首领使用现有动画GLB的体型、色调和冠饰变体，各自配置独立机制与数值；图鉴和关卡详情可查看应对提示。

七种输出塔可以攻击选定障碍；兵营的职责仍是派出守卫。清除树木、岩石、符文柱、宝箱分别奖励 20、30、45、65 金币，腾出的格子可以建塔，友军寻路也会立即释放该位置。清障时只有射程内的塔转移火力，其他塔继续防守；面板可以停止集中清障。暂停会冻结清障，重开会恢复障碍。

战场地形覆盖整个画布，HUD 和选择面板浮在地图之上。地图可以平移、缩放；关卡卡片、英雄选择、塔菜单和图鉴使用实际三维模型生成预览。入口为带符文石环和旋转涡流的时空门，正面对应道路行进方向。城顶有飘动的纹章旗，城墙后有住宅、市场、酒馆、铁匠铺、风车、水井和街道。住宅、酒馆与铁匠铺的实际烟囱口持续冒出随风上升、渐散的灰烟，风车的独立扇叶持续转动。八名居民日常走动，敌军进入任一城门附近8单位范围时发出惊叫，绕开建筑分散逃往不同街道和空地；到达后会继续寻找新路线，危险消失后恢复日常活动。居民属于生活场景，不增加受伤或疏散胜负条件。

霜岩边境四关及北境长夜有增强的飘雪和持续积雪。雪花采用大小分层、六角轮廓和蓝灰边缘，随风飘落；精简、标准、丰富效果分别绘制320、900、1440片雪花，共用一次绘制。高DPR屏幕按实际渲染比例调整雪花大小。怪物、英雄与塔的朝上表面随时间变白。暂停会冻结飘雪、积雪、烟雾、扇叶和居民动作，并立即停止声音。

第一波由玩家开始；后续每波敌军清完后立即发放补给并自动接上下一波，没有波间倒计时或预留等待。“第 X 波来袭”提示短暂显示2.2秒，不阻挡建造、升级和技能。最后一波清完正常结算胜利；无尽仍保存已守住的波数，每五波保留领主预警。

守城之心生命归零后，先播放约6秒的失守演出：镜头移向城镇，城堡石墙和屋顶破碎、旗帜倒下，怪物从城门分路进入街道并攻击房屋；房屋沿用原模型与贴图碎裂，废墟起火、冒烟并飘出火星。居民惊叫、分散逃跑，部分倒地或化为光点消失，保持奇幻卡通表现。演出结束后显示失败结算，也可随时点击右上角“跳过演出”直接结算。战斗结果在生命归零时就已确定，演出不改变金币、得分、击杀或已守住波次，也不增加居民伤亡玩法。重开会恢复城堡、房屋和全部居民，并释放演出资源。演出速度不受1×/2×战斗倍率影响；切到后台、转为竖屏或图形上下文中断时冻结，恢复显示后继续播放。

完成上一关后解锁下一关；重玩不会降低最高星级。基地初始 20 生命：胜利时保持 20 为三星，14–19 为二星，1–13 为一星。第 4、8、12 关包含独立机制的区域领主，第 12 关获胜显示正式战役通关结算。

无尽地图为翡翠环城、北境长夜、余烬永垒。三张地图从开始就能选择。每五波出现领主，后续波次加入支援与精英组合。普通敌军与Boss的生命、护甲、魔抗和行走速度逐波持续增长；开局保留原有生命成长斜率，后期逐步叠加成长。生命和移速移除旧的4.5倍/1.32倍硬上限；护甲和魔抗逐步接近84%，保持混合伤害和穿透的作用。Boss轮换保留此前已出现领主的最高基础强度，再叠加当前波次成长，后续领主的四项数值都高于上一位。铺满满级专精塔后仍会面临不断增加的压力。每波人数最多45、存活敌人最多88、击杀奖励倍率最多1.8，限制实体与经济数量。各地图独立保存最高已守住波数与最高得分；失败时当前未完成的波不算已守住。

## 英雄与敌人

| 英雄 | 解锁 | 被动与技能 |
| --- | --- | --- |
| 圣盾骑士 · 伊莱恩 | 初始 | 恢复与双阻挡；圣盾庇护、黎明震击 |
| 游林猎手 · 瑟芙 | 完成第 2 关 | 每第三箭增强；荆棘陷阱、穿云箭雨 |
| 星纹法师 · 阿斯特 | 完成第 4 关 | 普攻溅射；星陨爆发、时空凝滞 |
| 森灵祭司 · 莉萝 | 完成第 7 关 | 回春治疗；生命潮汐、古木守护 |

英雄自动攻击附近目标，移动指令会绕开塔、城堡、景物树干和石块。英雄死亡后 12 秒重生，不直接造成整场失败。召唤树灵会在 18 秒后消失。

十五种普通、精英及召唤敌人为：棘背小鬼、裂牙奔狼、荒原掠夺者、黑铁重卫、幽光灵体、夜翼蝠、霜羽鹰妖、骨杖巫医、晶甲祭卫、孢囊母虫、尖刺幼虫、熔铁攻城兽、血誓先锋、灰烬召唤师、霜铠巨人。游戏内图鉴给出职责、护甲、魔抗和应对方式。

三个领主：腐冠古树在阶段变化时召唤护卫，护卫存活时恢复；霜岩暴君提前预告冰封范围，然后进入碎甲爆发窗口；灰烬无冕王分三个阶段，并从其他入口增援。领主出现前有约两秒预警，期间冻结战斗模拟，暂停和设置不会跳过或重复预警。

物理护甲与魔抗分别处理对应伤害；护盾先于生命扣除；易伤、减速、短暂免控窗口与持续伤害都有实际规则。数字显示真实扣除量，护盾使用 ◇ 标识。普通敌人受伤后短暂显示血条，精英突出显示，领主使用顶部血条。

雪地建造模式使用蓝色四角描边；选中格子为深蓝边框与浅蓝底色，非法位置保留红色提示。四个雪地战役和北境长夜共享此样式，退出建造时网格降低透明度。描边用合并的三角形几何体保持可见宽度，整张网格只增加一次绘制。

## 战斗音效

18 种怪物从时空之门实际出场时播放对应的原创吼叫，狼、飞行怪、重甲与领主采用不同音高、呼吸噪声和声腔。道路中的召唤与分裂不会误播入口吼叫。多入口快速出怪最多同时播放三声吼叫，领主保留优先位置；音效混合有压缩和并发限制。

| 防御建筑 | 发射 / 攻击声音 |
| --- | --- |
| 箭塔 | 弓弦与箭矢破空 |
| 重弩塔 | 厚重弩弦和机械冲击 |
| 火炮塔 | 低频炮响、落地爆炸 |
| 奥术塔 | 能量升调与魔法振鸣 |
| 寒冰塔 | 冰晶鸣响与碎冰 |
| 雷霆塔 | 电弧爆裂与低频雷声 |
| 自然塔 | 孢子喷射与柔和气流 |
| 兵营塔 | 守卫挥剑金属声；斥候采用箭矢声 |

声音通过本地 PCM 合成与 Web Audio 播放，不需要在线音效资源、麦克风或媒体权限。音效音量控制全部出场、攻击、命中和爆炸声音；设为零立即静音，暂停或离开战斗会停止当前声音。首次点击游戏按钮解锁浏览器音频。

## 设置与保存

设置包含高清 / 均衡 / 流畅画质、精简 / 标准 / 丰富特效、震动强度、地图操作灵敏度、音乐音量、音效音量、伤害数字和恢复默认值。新存档默认均衡画质与标准特效，三维画面预算350万像素；手动高清仍提供650万像素预算。菜单与暂停画面上限30帧，战斗上限60帧，后台页面停止绘制，HUD 数字使用独立画布。

密集击杀时，建造和升级面板原位更新金币对应的按钮状态，保留图标、滚动位置和目标优先级焦点；Boss生命条与完整数字也原位刷新。后期二倍速采用单次扫描选敌、缓存塔属性和弹体目标，复用弹体几何体、命中特效与雷霆缓冲区，粒子和闲置特效池保持数量限制，重开与切换地图释放资源。优化不调整攻击间隔、伤害、目标优先级或无尽逐波成长规则。性能与稳定性验证的场景、数据和软件渲染限制见 `TESTING.md` 最新记录。

遇到打开预览时整屏短暂黑屏，可以使用 [均衡预览](http://127.0.0.1:5175/?safe=1)。该地址让当前访问使用均衡画质和标准特效，包括已有高清设置的浏览器；打开地址本身不写入已保存的设置或进度。需要长期使用均衡时在游戏设置中选择并保存。2026-10-06 的本机显卡事件与应用侧处理见 `docs/GPU-DIAGNOSTIC.md`。

本游戏使用独立的 `realm-wardens.save.v1` 与 `realm-wardens.settings.v1` 命名空间。保存战役星级、解锁、无尽纪录、已读提示和设置。存储禁用、损坏或版本不符时安全回退；重置进度必须经过确认，不会删除画面和声音设置。
